## 📌Project Overview
This project analyzes hospital patient data to track key healthcare metrics and trends.

## 📈 Key Metrics
- Total Patients
- Average Stay Duration
- Total Treatment Cost
- Readmission Rate

## 📊 Dashboard Features
- KPI Cards with dynamic values
- Disease Distribution Analysis
- Patient Admission Trend (Monthly)
- Department Workload Analysis
- Interactive Filters (Gender, Age Group, Year, Readmitted)

## 🛠 Tools Used
- Power BI
- Excel

## 🚀 Key Insights
- Identified most common diseases
- Analyzed patient admission trends
- Highlighted high workload departments
- Tracked readmission patterns
